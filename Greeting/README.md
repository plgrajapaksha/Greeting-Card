# 🎂 3D AR Birthday Greeting Card

## 📌 Project Description

The 3D AR Birthday Greeting Card is an Augmented Reality web application developed using A-Frame and AR.js.

The application displays a beautiful interactive 3D birthday greeting card when a user scans a Hiro marker using a camera.

It combines 3D objects, animations, and interactive features to create an enjoyable birthday greeting experience.

## 🎯 Project Objectives

- To develop an interactive Augmented Reality greeting card.
- To display 3D objects using a Hiro marker.
- To demonstrate animations in an AR environment.
- To implement user interactions with 3D objects.
- To provide an engaging and creative digital greeting experience.

## ✨ Main Features

### 1. 3D Greeting Card
- Birthday greeting message.
- Decorative card background.
- Beautiful colours and design.

### 2. 3D Balloons
- Three colourful balloons.
- Floating animations.

### 3. 3D Birthday Cake
- Pink birthday cake.
- Cream decoration.
- Birthday candle with animated flame.

### 4. 3D Gift Box
- Decorative gift box.
- Gold ribbon.

### 5. Animated Decorations
- Rotating 3D star.
- Animated hearts.
- Floating balloons.
- Animated candle flame.

### 6. Interactive Colour-Changing Ball
- Users can click the ball.
- The ball changes between different colours.

### 7. Marker Detection
- Uses the Hiro marker.
- Displays a message when the marker is detected.
- Displays another message when the marker is lost.

## 🚀 How to Run the Project

1. Download or clone the project.
2. Open the Assignment folder in Visual Studio Code.
3. Open the index.html file.
4. Run the project using Live Server.
5. Allow camera permission when requested.
6. Show the Hiro marker in front of the camera.
7. View the 3D birthday greeting card in Augmented Reality.

**Note:** For mobile phone testing, the project must be hosted on an HTTPS server.

## 🎮 User Interactions

- Scan the Hiro marker to display the AR greeting card.
- Click the blue ball to change its colour.
- Observe the animated balloons, hearts, star, and candle flame.

## 📷 AR Marker

This project uses the standard Hiro marker provided by AR.js.
